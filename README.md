# OEOO Philippines — flat GitHub website

All files are in ONE folder. Upload the contents of this folder directly to the root of your GitHub repository. Do not upload the ZIP itself.

## Files
- index.html — homepage
- about.html — organization
- projects.html — work and projects
- get-involved.html — ways to participate
- donate.html — donation page (DEMO ONLY; no payments processed)
- styles.css — main website styles
- script.js — main website interactions
- field-atlas.html — interactive map
- field-atlas.css — map styles
- field-atlas.js — map coordinates and behavior
- oeoo-logo.png — brand logo
- field-vessel.jpg — website photograph
- .nojekyll — GitHub Pages configuration

## Preview
Open this folder in VS Code and start Live Server on index.html.

## Publish
GitHub repository → upload all files → Settings → Pages → Deploy from branch → main / (root).

## Important
Donation controls are a preview and do not accept money. Connect only an OEOO-approved payment platform before fundraising. The field map contains real coordinates; confirm publication permission before making the repository public.
